# Security

## Authority Boundary

This software operates within the Mermicorn Grove federation.

### Who May Act
- Cherry (operator)
- Authorized Mermicorn services

### Data Classification
| Data | Classification |
|------|---------------|
| Source code | Public |
| API keys | Private |
| User data | Private |

### Security Principles
1. No credentials in output
2. All operations auditable
3. Authority bounded per action
