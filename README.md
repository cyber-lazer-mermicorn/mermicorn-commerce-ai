# Mermicorn Commerce AI

**Product intake, comparison, listings, campaigns, marketplace adapters, and sales analytics.**

## 1. What this project does
Turns any researched opportunity into a verified multichannel sales package — structured records, pricing, listings, leads, and campaign assets.

## 2. Who it is for
Cherry and every commerce vertical (travel, coins, auto, ravewear).

## 3. What exists today
Foundation structure and shared contract.

## 4. What is planned
One complete product converted into a verified multichannel sales package as the first proof.

## 5. What it does not claim
Does not execute real payments, bookings, or marketplace listings without human confirmation and proper credentials. Public code only; operational data stays private.

## 6. First proof artifact
One product converted into a verified multichannel sales package (record + comps + listing + campaign assets).

## 7. Shared Mermicorn services
Core commerce service consumed by all verticals. Works with graphic-ai for assets and token-saver for efficiency.

## 8. Information that remains private
Customer data, leads, internal pricing, and credentials live in mermicorn-private-ops or the private vault.
